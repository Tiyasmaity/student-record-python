# Student Record Python

## Description
A simple Python program to store student names and marks using lists.

## Features
- Display student records
- Search for a student
- Find highest score
- Find lowest score
- Sort students by marks

## Technologies Used
- Python

## How to Run
Run the program using:

py student_records.py

## Sample Students
- Rahul - 85
- Priya - 92
- Amit - 78
- Sneha - 95

## Output
The program displays student records, searches for students, finds the highest and lowest scores, and sorts students according to marks.
